# MockMate AI 🤖

MockMate AI is an AI-powered mock interview platform designed to help users practice technical interviews and improve their interview performance.

The application uses Google Gemini AI to generate role-specific interview questions and evaluate candidate answers with personalized feedback.

## 🚀 Features

- User registration and login
- Role-specific interview question generation
- Difficulty selection
- Custom number of interview questions
- AI-powered interview evaluation
- Overall interview score
- Question-wise feedback
- Strengths and improvement suggestions
- Interview history
- Performance statistics
- Profile and achievements
- Responsive user interface
- Dark and light theme support

## 🛠️ Tech Stack

### Frontend

- React.js

- Context API

### Backend

- Node.js
- Express.js
- REST APIs

- MongoDB Atlas

- Google Gemini API
